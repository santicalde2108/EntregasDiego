CREAR Y ACTIVAR EL AMBIENTE VIRTUAL
(Ejecutar en la terminal, dentro de la carpeta del proyecto)

1. Crear el ambiente:
   Windows:          python -m venv venv
   Mac / Linux:      python3 -m venv venv

2. Activarlo:
   Windows (PowerShell):   venv\Scripts\Activate.ps1
   Windows (CMD):          venv\Scripts\activate.bat
   Mac / Linux:            source venv/bin/activate

   Sabrás que está activo porque aparece (venv) al inicio de la línea de la terminal.

3. Instalar las librerías:
   pip install -r requirements.txt

4. Ejecutar el programa:
   python main.py

5. Para salir del ambiente:
   deactivate

Nota: si PowerShell muestra un error de permisos al activar, ejecuta una sola vez:
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
